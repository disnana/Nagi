# キューとworkerの試験

キューは、受け付けた仕事をworkerへ順に渡す仕組みです。Nagiの検証用実装は、64件までのキューと最大8個のworkerを使います。

[queue.nagi](../examples/queue.nagi)では、40件の仕事のうち36件が完了し、4件が再試行後も失敗します。失敗時には1ミリ秒、2ミリ秒の間隔を空けて再試行し、上限に達したものを処理できなかった件数として記録します。終了時には送信側とworkerの終了を待ちます。

任意の処理をキューへ登録するAPI、仕事や再試行の永続保存、プロセス再起動後の復元には未対応です。再試行では同じ処理が複数回走る場合があります。重複実行をどう扱うかは、汎用APIの設計時に決める必要があります。
