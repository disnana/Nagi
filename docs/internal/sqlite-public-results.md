## 設計・公開境界

Q002/Q004の承認範囲でstd.db.sqlite Pool/Tx APIを開発sourceへ追加した。runtimeは既存Tokio FIFO semaphoreとlazy worker adapterを使い、deadpool/deadpool-runtimeを除去した。新crate・Tokio/rusqliteの版更新はない。ALLOCATIONは明示的なfallible reserveの失敗分類であり、任意のOOM/allocator abortから回復する保証ではない。

公開surfaceは8 type/resourcesと18 operations。既存db_* APIは維持される。新APIは未リリースであり、本文の例はrepository sourceからbuildしたcompilerが必要。旧Dbとの機械的な置換、全API利用例の実行、全Rust targetの検証、配布済みarchiveの受入を、この記録のテスト数から推測しない。
