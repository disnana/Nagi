# SF02 canonical Session compiler candidate

This source milestone connects the adopted Session contract to the existing canonical standard-resource registry, operation Passing metadata, capability walk, checker, and sealed emission path. It adds six opaque resources, eleven Session operations, and two HTTP policy factories; it adds no syntax, checker, raw secret conversion, JWT verifier, or generic protected Query API.

The runtime signatures are compared with PR #113 head `bf040ce13a4509036a028607aeaa1dc34399d718`. SessionResponse remains SameTask and nonCopy/nonClone/nonSerde/nonDebug/nonshared/nonfield. Owned local Option/Result and same-task call/return remain permitted. Store uses explicit clone and permits owned fields/shared state. Failure.message borrows argument zero. SameSite.NONE is represented but Store startup rejects it until the SF03 guard exists.

All tests in this compiler milestone are **unexecuted**: three canonical metadata unit tests, three integration tests containing four positive and sixteen negative High/independent saved Low/handwritten Low cases, and one startup scenario with three native forms. Rustfmt and CI syntax checks are source checks only. No import/parser failure counts as ownership acceptance. Negative expectations require successful source loading followed by the intended checker reason and exact primary line. Saved Low expectations follow explicit lowering origin from the fixed High offending line; handwritten Low has its own fixed line. The primitive print rejection is not a native Debug trait proof.

The native harness preserves raw generated Rust before its separate adapter/assertions. It uses actual startup/open, explicit shared Store clone and Pool close; it does not issue a credential or claim complete Session business/HTTP coverage. Existing runtime native evidence and its Windows/clippy failures are separate. Normal Cargo, compiler semantic execution, native three-form results, public Rust trait negatives, browser/TLS and four-OS acceptance remain gates. G3 and protected SessionExecution remain later milestones.

The full existing CI pipeline is preserved, with added exact three-test guards for each new harness. The resource/operation characterization inventories change from 39/85 to 45/98 and retain their independent expectations. This status must be updated from actual immutable-source CI results before claiming the public Nagi Session feature complete.
