# SF01 compiler HTTP test migration map

This map records the compiler HTTP test changes made for the D1–D3 contract in [decisions-and-migration.md](decisions-and-migration.md). The standard entry is an explicit `App`/`route` with a policy argument and a handler authority argument. Existing policy-free routes, decorators, and unqualified legacy `serve` calls are migration diagnostics; no compatibility coexistence path is retained.

## Test harness and migration boundaries

The executable compiler probes use `CARGO_BIN_EXE_nagic run ... --no-project`, `NAGI_ROOT`, and the shared `NAGI_NATIVE_TARGET_DIR`; the request and DTO cases use small inputs and no long-running listener. `http_codegen.rs` retains the checked-emission seal before Rust output comparison. Dynamic path conflicts are checked through the actual public route registration result, not by relaxing the former test to accept any compile success.

The standard route contract no longer models decorator-extracted request DTOs. Applications receive the raw request and select an explicit decoder; Deserialize rejects unsupported private fields. Ordinary JSON DTO and optional payload representations remain covered by native High and saved Low. Typed HTML is still future work under SF04, and this migration map does not claim that `text`, `bytes`, or headers provide its security properties.

## その他の契約を偶然成功にしないための移行

`build_diagnostics`のimported async FFI Send負例は明示public Policyと第3引数unitへ移行し、同じRust Send原因note・High/import元行・保存Low行を実Cargoで確認する。

退役HtmlをJSON/DB/field/scope型の負例へ混ぜると先のmigration拒否が目的diagnosticを隠すため、`builtin_type_contracts`に独立したmigration検査を追加し、現役型に対する元契約を維持する。所有field消費の旧html呼出は所有strを返す通常関数へ変更し、移動後元field利用の拒否を維持する。現在のhttp.textは借用APIであり、この所有transferの代用にしない。Listのawait結果推論は旧serveから現役db_openへ移し、async Resultと所有引数の推論目的を維持する。

旧transportを参照したconformance harness登録は現在のpanic boundaryへ更新し、SF01 checker/native/公開runtimeも明示登録する。登録成功とテスト実行成功を区別する。
