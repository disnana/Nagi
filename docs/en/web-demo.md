# Task management JSON API demo

The demo registers explicit public Policies through standard HTTP. Its CRUD JSON API, validation, persistent SQLite data and result errors are verified through native requests. It does not publish an active HTML page. Nagi 0.2.0 includes a typed HTML subset, but this sample has not migrated its browser UI.

Follow the complete [English sample guide](../../test-nagi-code/web-demo/README.en.md) for the working directory, commands, port/database settings, expected API outputs and smoke checks. [Published 0.1.11 sources](https://github.com/disnana/Nagi/tree/nagi-v0.1.11/test-nagi-code/web-demo) preserve the historical HTML example.
