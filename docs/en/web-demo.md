# Task management API demo (unreleased SF01)

The development-source demo registers explicit public Policies through standard HTTP. Its CRUD JSON API, validation, persistent SQLite data and result errors are verified through native requests. It does not publish an active HTML page in SF01. Typed HTML and equivalent browser UI migration remain the SF04 step.

Follow the complete [English sample guide](../../test-nagi-code/web-demo/README.en.md) for the working directory, commands, port/database settings, expected API outputs and smoke checks. [Published 0.1.11 sources](https://github.com/disnana/Nagi/tree/nagi-v0.1.11/test-nagi-code/web-demo) preserve the historical HTML example.
