## すぐ確認する

- [ターゲット別の対応表](./support)：公開Rustターゲットと開発中Goターゲットを区別します。
- [`std.http.server`の応答上限](./http-response-limits)：12個の値の名前、単位、失敗条件を確認します。
- [変更履歴](../changelog)：公開済みの版と未リリース変更を分けます。
- [完全なソース例](https://github.com/disnana/Nagi/tree/main/test-nagi-code)：HTTP、SQLite、Actor、Rustアダプターのプロジェクトです。
- [公開版の取得](https://github.com/disnana/Nagi/releases/tag/nagi-v0.2.3)：Nagi 0.2.3のコンパイラと配布物です。

API名だけを探す場合も、最初に対象版とターゲットを確認してください。`Unreleased`の構文や0.3.0向けGo実装は、公開Nagi 0.2.3に含まれません。
