backends: [rust]

公開済みの性能値は、host、toolchain、プロファイル、キャッシュ状態、試行回数を含む条件と一緒に読みます。小さな同期プログラムのビルド結果をHTTPやSQLiteへ一般化せず、短時間のActor測定を長時間サーバー性能と呼びません。

[正本の測定記録](https://github.com/disnana/Nagi/blob/main/PERFORMANCE.md)には生データと制約があります。
