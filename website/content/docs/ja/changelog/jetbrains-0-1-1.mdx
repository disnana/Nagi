- IntelliJ IDEA/PyCharmプラグインの最初の正式GitHubリリースです。既存のHigh/Low色付け、字下げ、折りたたみ、check/runコマンド、ガターの実行ボタンを含み、対応するIC/PC ZIPをディスクから導入します。コンパイラは別途必要で、この版はJetBrains Marketplaceへ公開しません。
