コード マップ、std.Actor、std.http.サーバー、型・ownership検査、エディター標準モジュール補助を追加した同時版です。

- 正本ID：`nagi-0-1-8-vscode-0-1-10`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- 共有グラフ IRによる静的`map types`・`map modules`・`map calls`を追加し、Mermaid・D2・JSON・単独 HTML、focus表示、任意のD2 SVG/PNG出力に対応します。

{/* canonical-item: item-002 */}
- リリース 注記へ確定バージョンの変更要約、前component リリースとコミット比較、PR、contributor情報を含めます。

{/* canonical-item: item-003 */}
- 呼び出し/Listの一時借用と衝突するmoveを診断し、単独 所有-値式を検査時に消費します。scalar `owned[T]` class フィールドは生成Rustのコピー動作と一致させます。

{/* canonical-item: item-004 */}
- DocsのHTTP/Actor topic配下にAPI 参照と計測を置き、現在 ページ、sidebar scroll、mobile contents menuを維持します。

{/* canonical-item: item-005 */}
- Docs 成果物/リンクを`nagi.disnana.com/`で配信しつつフォークのプロジェクト/利用者 Pages既定を保ちます。domain/Pagesだけの変更は完全 Rust checkをskipしますが、CI config変更は完全 checkします。

{/* canonical-item: item-006 */}
- 型付き message/応答、所有 状態 transition、named async 生成関数/ハンドラー、restart 方針、lifecycle イベント、tracked 停止を持つ`std.actor`を追加し、業務 エラーをハンドラー/呼び出し 失敗から分離します。

{/* canonical-item: item-007 */}
- Actor message/応答/エラー payloadの所有 容量を検査し、未対応マップ/shared/借用した/非公開 グラフをネイティブ生成前に拒否します。別負荷したLowでもActor 同一性とジェネリック 引数を維持します。

{/* canonical-item: item-008 */}
- 複数登録標準モジュールの補完/シグネチャ/読み取り専用 定義 移動と、状態更新・業務 失敗・明示停止を持つSupervisor/HTTP sampleを追加します。

{/* canonical-item: item-009 */}
- DB不要アプリ、ネイティブ Method/Status、リクエスト ヘッダー、型付き shared 状態、async ハンドラー、アプリ/経路 エラー mappingを持つ`std.http.server`を追加し、ヘッダー/本文/admission/応答送信/停止を有限にします。

{/* canonical-item: item-010 */}
- 登録標準モジュール インポート、comma区切りfrom インポート、Some/Noneによるexhaustive Option matchを追加し、保存済み Lowで資源 同一性と借用 生存期間を維持します。

{/* canonical-item: item-011 */}
- VS Codeの補完/hover/シグネチャ ヘルプ/読み取り専用 定義 移動を標準資源・定数・operationへ拡張します。

{/* canonical-item: item-012 */}
- assignmentなしでprint/compareするinteger リテラルを含め、検査済み 数値 型を生成Rustで維持します。

{/* canonical-item: item-013 */}
- speculative indexing後のパーサー nesting depthを復元し、try/await フィールド/索引 receiverの括弧を保持し、未対応class 型 引数を破棄せず拒否します。

{/* canonical-item: item-014 */}
- control characterを含む文字列 byteをHigh→Low→Rust生成で維持します。

{/* canonical-item: item-015 */}
- 組み込み GET endpointまたは等価capture パスと衝突する経路をHTTP router構築前に診断します。

{/* canonical-item: item-016 */}
- 以前のstatement 件数ではなく、trigger変更を含む現在の`db_exec` SQL batchだけの変更数を返します。

{/* canonical-item: item-017 */}
- VS Code 型 annotationへコンストラクター引数なしのclass名を挿入し、ローカル 関数 値のhover 型を維持します。
