コードマップ、`std.actor`、`std.http.server`、型・所有権検査、エディター標準モジュール補助を追加した同時版です。

- 正本ID：`nagi-0-1-8-vscode-0-1-10`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- 共有グラフIRによる静的`map types`・`map modules`・`map calls`を追加し、Mermaid・D2・JSON・単独HTML、フォーカス表示、任意のD2 SVG/PNG出力に対応します。

{/* canonical-item: item-002 */}
- リリースノートへ確定バージョンの変更要約、前のコンポーネントのリリースとコミット比較、PR、コントリビューター情報を含めます。

{/* canonical-item: item-003 */}
- 呼び出し/Listの一時借用と衝突するmoveを診断し、単独の所有値式を検査時に消費します。スカラーの`owned[T]`クラスフィールドは生成Rustのコピー動作と一致させます。

{/* canonical-item: item-004 */}
- DocsのHTTP/Actorトピック配下にAPI参照と計測を置き、現在のページ、サイドバーのスクロール、モバイルの目次メニューを維持します。

{/* canonical-item: item-005 */}
- Docs成果物とリンクを`nagi.disnana.com/`で配信しつつ、フォークのプロジェクト/ユーザーPages既定を保ちます。ドメイン/Pagesだけの変更では完全なRust検査を省略しますが、CI設定変更では完全検査します。

{/* canonical-item: item-006 */}
- 型付きメッセージ/応答、所有状態の遷移、名前付き非同期生成関数/ハンドラー、再起動方針、ライフサイクルイベント、追跡可能な停止を持つ`std.actor`を追加し、業務エラーをハンドラー/呼び出し失敗から分離します。

{/* canonical-item: item-007 */}
- Actorメッセージ/応答/エラーペイロードの所有容量を検査し、未対応のマップ、共有、借用、非公開グラフをネイティブ生成前に拒否します。別途読み込んだLowでもActorの同一性とジェネリック引数を維持します。

{/* canonical-item: item-008 */}
- 複数登録標準モジュールの補完/シグネチャ/読み取り専用の定義移動と、状態更新・業務エラー・明示停止を持つSupervisor/HTTPサンプルを追加します。

{/* canonical-item: item-009 */}
- DB不要のアプリ、ネイティブのMethod/Status、リクエストヘッダー、型付き共有状態、非同期ハンドラー、アプリ/経路エラーのマッピングを持つ`std.http.server`を追加し、ヘッダー・本文・受け入れ・応答送信・停止に上限を設けます。

{/* canonical-item: item-010 */}
- 登録標準モジュールのインポート、カンマ区切りのfromインポート、Some/Noneによる網羅的なOptionのmatchを追加し、保存済みLowで資源の同一性と借用の生存期間を維持します。

{/* canonical-item: item-011 */}
- VS Codeの補完/ホバー/シグネチャヘルプ/読み取り専用の定義移動を標準資源・定数・操作へ拡張します。

{/* canonical-item: item-012 */}
- 代入せずにprint/compareする整数リテラルを含め、検査済み数値型を生成Rustで維持します。

{/* canonical-item: item-013 */}
- 先読みの索引処理後のパーサーの入れ子深さを復元し、try/awaitのフィールド/索引の受け手の括弧を保持し、未対応クラス型引数を破棄せず拒否します。

{/* canonical-item: item-014 */}
- 制御文字を含む文字列バイトをHigh→Low→Rust生成で維持します。

{/* canonical-item: item-015 */}
- 組み込みGETエンドポイントまたは同等のキャプチャパスと衝突する経路をHTTPルーター構築前に診断します。

{/* canonical-item: item-016 */}
- 以前の文の件数ではなく、トリガーによる変更を含む現在の`db_exec` SQLバッチだけの変更数を返します。

{/* canonical-item: item-017 */}
- VS Codeの型注釈へコンストラクター引数を伴わないクラス名を挿入し、ローカル関数値のホバーの型を維持します。
