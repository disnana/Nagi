既定配布ビルドを維持したまま、開発用ビルド、差分ビルド、CI生成、キャッシュ調査、ランタイム保守を追加した版です。

- 正本ID：`nagi-0-2-1`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- 0.2.0互換のビルド・検査・安定性改善を公開します。高速な開発には`nagic run app.nagi --profile dev`を明示指定で使い、通常CLIはリリース既定です。初回ネイティブビルドはRust依存をコンパイルし、差分モードも型・所有権・能力検査を省略しません。IDEプラグインは別バージョン・別公開です。

{/* canonical-item: item-002 */}
- ランタイムでTokio 1.54.1以上を要求し、ワークスペース/検査用データロックを1.54.1へ更新してタイマードライバー同期修正を取り込みます。従来ロックは影響版1.54.0ではなく1.53.1/1.53.2でした。生成アプリケーションは独立ロックを持つため、直下のロック更新だけでなく新ランタイムで再ビルドしてください。

{/* canonical-item: item-003 */}
- 最初の停止要求が停止を公開するまでSupervisorイベントストリームを開き、同時後始末完了による早期終了を防ぎます。子タスクの合流、取り消し、STOPPED、停止期限を維持し、決定的回帰と監督対象ワーカーの正確なイベント数を追加します。

{/* canonical-item: item-004 */}
- 明示した世代のルートとCargoキャッシュのルートを有限・読み取り専用で調べる`nagic cache inspect`を追加します。論理サイズ、不完全な走査、情報を失わないOSパスを報告しますが、削除、回収可能量の断定、ネイティブ成果物再利用の承認には使いません。

{/* canonical-item: item-005 */}
- ソース読み込みでパーサーの元物理モジュールのトークンを再利用して2回目の字句解析を避け、完全なHigh/Low検査と診断を維持します。フロントエンド回帰検査用データ間でCargo依存関係ターゲットを共有し、未使用の重複するCIリリース用コンパイラビルドを削除しますが、テストと配布ビルドは維持します。

{/* canonical-item: item-006 */}
- ランタイム編集、破損ロック拒否、旧実行ファイル保護を含む、再現可能な完全検査と8分岐の通常ビルド対unitsビルドベンチマークを追加します。遅い分岐とキャッシュ条件も別に報告し、リリース既定は変えません。

{/* canonical-item: item-007 */}
- 明示指定 `--profile dev --incremental=units`で、閉じたプリミティブ型だけを扱う同期関数を依存順の最大8つのCargoライブラリへまとめます。未対応関数・非同期関数・ユーザー型はファサードに残し、影響を受ける単位と逆依存だけを再ビルドします。完全検査と不変な世代を必須とし、受領記録スキーマ 3でソース単位の閉包を検証し既存スキーマを維持します。

{/* canonical-item: item-008 */}
- 明示指定 `--profile dev --incremental`で生成Rust本文を不変なコンテンツアドレス方式のCargoライブラリとして再利用し、各世代はエントリー用shimだけをコンパイルします。完全検査、Cargo検証、旧実行ファイル保護、破損キャッシュ拒否を維持し、アダプター・追加の依存関係・管理対象の実行はモノリシックのままです。受領記録スキーマ 2を追加しスキーマ 1と公開0.2.0既定を維持します。

{/* canonical-item: item-009 */}
- 明示指定 `build/run --profile dev|release`を追加し、リリース既定とデバッグ/リリースのオーバーフロー動作を維持します。完全なNagi検査、Cargo依存関係の検証、世代隔離、不変成功実行ファイルを保ちます。

{/* canonical-item: item-010 */}
- 明示指定 `--build-stats`で型付き宣言/関数変更観測、依存関係グラフ、Cargo成果物数、フェーズ時間を出します。公開成果物ハッシュを記録・検証しますが、意味的な観測はネイティブ再利用や検査/テスト省略を承認しません。

{/* canonical-item: item-011 */}
- 標準ライブラリだけで動くPython製のCI生成・受領記録検証ツールを同梱します。公開0.2.0互換ワークフロー、信頼済み既定ブランチへのpushだけのキャッシュ書込み、フォークからのキャッシュ読み取りを文書化し、破損レコード、非通常ファイルの成果物、リンク/reparse pointのパスを拒否します。

{/* canonical-item: item-012 */}
- 既存セキュリティAPIの保証、未対応通信、段階的ビルドのロードマップを、アプリケーションビルド実測と制約付きで文書化します。既存0.2.0バイナリは不変です。関数単位分割は未変更再ビルドを改善した一方、編集分岐を遅くしたため明示指定のままです。
