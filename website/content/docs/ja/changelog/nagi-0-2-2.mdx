小さな変更の開発待ち時間と初回依存解決を改善しながら、0.2.1互換と完全な検査を維持した版です。

- 公開日：`2026-10-27`
- 正本ID：`nagi-0-2-2`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- 0.2.1互換、既定の完全ランタイムとリリースビルド、完全なHigh/Low・型・所有権・方針検査、Cargoのネイティブ鮮度判定、旧成功成果物を維持し、対応範囲の編集ループと初回依存解決の再現性を改善します。エディタープラグインは別バージョン・別公開です。

{/* canonical-item: item-002 */}
- 検査済みIRから選ぶ明示指定のランタイム依存関係選択を追加します。既定の完全構成と既存Rust APIを維持し、完全検査済みの小さな同期プログラムだけ共有ソースのcoreパッケージを使います。未知の処理・非同期処理・アダプター・追加の依存関係・差分がある場合は完全構成へフォールバックし、計測結果を任意のHTTP/SQLバックエンドへ一般化しません。

{/* canonical-item: item-003 */}
- `build`/`run`へ明示`--seed-lock`を追加します。出力にロックがない場合だけ初期Cargoロックを使い、既存または破損ロックは置換しません。seedは整合性確認済みの解決入力であり、ネイティブ成果物キャッシュや署名ではありません。コールド状態の完全比較では遅かったため既定では無効です。

{/* canonical-item: item-004 */}
- `rustls`、`rustls-webpki`、`webpki-roots`を修正版へ更新し、旧アプリケーションロックの再解決時に修正済みWebPKI依存を要求します。既存生成ロックと実行ファイルは自動更新されないため、新ランタイムで再ビルドしてください。

{/* canonical-item: item-005 */}
- 既存のドキュメントCI経路では、検出可能な直下のwebsiteだけの変更に最適化を限定します。未知ファイルやコンパイラ/ランタイム/セキュリティ/依存関係混在変更は完全検証を維持し、Nagiアプリケーションのビルド動作は変えません。

{/* canonical-item: item-006 */}
- 利用者プロジェクト向けCI生成機能へ`--build-profile dev|release`を追加し、既定リリースと完全検査を維持します。生成ワークフローは`--nagi-version 0.2.2`なしでは0.2.1を対象にし、信頼済み分岐だけのキャッシュ書込み、旧CLI互換、プロファイル別キャッシュを維持して未対応組合せを事前拒否します。

{/* canonical-item: item-007 */}
- 互換性を保つ`read_line(prompt)`を`read_line()`と併設します。プロンプトは借用され、入力前に書き込み・フラッシュし、各I/O失敗を明示`Result`で返します。コンパイラ所有のエディターメタデータへ`read_line`と組み込み語彙を追加し、対応するエディターリリースが独立に利用します。

{/* canonical-item: item-008 */}
- 実行可能な日英結果/`try`教材、タスク管理JSON/SQLite API通し教材、検証バージョンと制約を示したFastAPI/Quart比較を追加します。

{/* canonical-item: item-009 */}
- BrowserLoginとSession期限失敗後の有限CI診断を、失敗リクエストの結果やテスト条件を緩めず改善します。リリースレベルのCIで観測した有効リクエストの断続的504は修正済みと証明されておらず、後の再試行成功と保持診断は調査証拠です。

{/* canonical-item: item-010 */}
- ランタイムプロファイルとロックシードは明示モードのままです。Nagi検査を省略せず、ネイティブ成果物を復元せず、全バックエンドをcoreランタイムにせず、一般的なビルド/ランタイム性能向上を証明しません。計測条件・未対応分岐・フォールバック理由を各機能に記載します。
