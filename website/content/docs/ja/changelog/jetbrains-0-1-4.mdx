ホバー/クイックドキュメント、入力中の色保持、引数情報、IDE実行を改善した版です。

- 正本ID：`jetbrains-0-1-4`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- 正確な関数・クラス・変数を対象に、利用可能な引数、戻り値、フィールドを含むコンパイラ連携のホバー／クイックドキュメントを追加します。UIスレッドを待たせたりRustビルドを始めたりせず、有限待機、取消、現在のスナップショット、信頼済みプロジェクトの制限を維持し、不明な組み込みシグネチャを捏造しません。

{/* canonical-item: item-002 */}
- 無効になった型・診断・移動情報とは独立に、背景解析中も未変更の識別子の色を表示します。変更されたトークンと強制無効化された表示データは、有限の所有範囲で破棄します。

{/* canonical-item: item-003 */}
- 元の説明、不明な詳細、修正案を保持しながら、診断ツールチップをエスケープ済みの読みやすい枠で表示します。引数情報にはコンパイラが返した戻り値型を表示します。

{/* canonical-item: item-004 */}
- Enterで手動選択したHighの字下げを保ち、連続Enterで1ブロックずつ抜ける操作を追加します。区切り記号内の継続、Lowの波括弧、スマート字下げ設定、元に戻すを維持し、対応済みのHigh `else`/`case`見出しとHigh/Lowの単独閉じ記号を既知の所有元へ揃えます。文脈不明時は通常入力を変えません。

{/* canonical-item: item-005 */}
- コンパイラが対応を通知した場合、IDE実行の既定をDevelopmentにし、実行設定ではリリースを明示選択できます。UIスレッド外で有限な能力確認を行い、既知の旧コンパイラは説明付きでリリースを維持します。不明・失敗した確認で暗黙に実行せず、CLI既定値とCheckは変えません。

{/* canonical-item: item-006 */}
- 古い実行環境が閉じる際、受理済みの新しいRun記述子まで破棄し得た標準Run引き渡し競合を修正します。引き渡し前の取消と、プロジェクト終了時のプロセス整理を維持します。報告されたWindowsでコンソール全体が緑色になる表示は新候補での検証が必要です。

{/* canonical-item: item-007 */}
- 関数・クラス・変数のホバー説明、初回解析待機、入力中の色保持、診断表示、編集補助を改善し、IDEのDevelopment Runと画面引き渡し修正を含めます。既存プラグインIDとIDEA/PyCharm共通ZIPを維持し、先行候補のホバー受入を追加修正後のGUI確認へ流用しません。

{/* canonical-item: item-008 */}
- 0.1.4の公開候補を準備します。利用者はホバー／色の候補を確認しましたが、網羅的なGUI検証ではありません。最終版の必須CIと4つのIDEテスト/Verifier経路が成功した後だけ公開します。GitHubリリースとMarketplaceの送信・承認は別工程です。PyCharm Pythonとの全面的同等性、ファイル全体整形、Rename、自動インポートは対象外です。
