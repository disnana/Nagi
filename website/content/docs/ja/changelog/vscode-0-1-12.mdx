保存、ビルド/run診断、補完、標準モジュール操作、Low編集、スニペットを改善した版です。

- 正本ID：`vscode-0-1-12`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- プロジェクト外を含む到達可能な未保存インポートをLower、ビルド、Runの前に保存します。保存失敗、別名衝突、入力保存中のエントリー変更があれば停止します。

{/* canonical-item: item-002 */}
- 未変更ソースのcheckと重複させず、対応位置付きのビルド/run失敗をProblemsに表示します。閉じたバッファ、symbolic リンク、Windows パスの大文字小文字をまたいでインポートファイルの診断を更新します。

{/* canonical-item: item-003 */}
- 依存関係スナップショットが有効な間、無関係なプロジェクトの診断と保留中checkを維持します。

{/* canonical-item: item-004 */}
- 名前の隠蔽されたローカル名を、コンストラクターや呼び出し引数を挿入せずに補完します。借用されたループ変数には読み取り専用の借用ヒントを表示します。

{/* canonical-item: item-005 */}
- quote付きfrom-インポート補完では宣言名だけを挿入し、結果のOk/Err pattern補助を追加し、補完と定義 lookupでファイル 別名を一貫して解決します。

{/* canonical-item: item-006 */}
- 新しい結果、HTTP、Supervisor操作に補完、hover、シグネチャ、定義対応を追加します。

{/* canonical-item: item-007 */}
- 波括弧折りたたみ、言語固有の宣言ヘルプ、インポート補完、エントリー/インポート スニペットでLow編集を改善します。

{/* canonical-item: item-008 */}
- データベース不要のasync エントリー 箇所とHTTP アプリ スニペットを生成し、High スニペットをNagi コンパイラでcheckします。

{/* canonical-item: item-009 */}
- VSIX パッケージを再現可能にし、導入コマンドを固定バージョン filenameに依存させません。
