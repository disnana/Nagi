型付きタスク結果、明示move、安定したビルド世代、封印された検査済みプログラムを追加した版です。

- 公開日：`2026-10-07`
- 正本ID：`nagi-0-1-11`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- High、保存済みLow、手書きLowにスコープローカルなタスク結果ハンドルを追加します。各結果型は一度の`await`か明示的な破棄を必須とし、moveはハンドルと責務を移します。内側の業務`Result`と保持される`TaskFailure`を分離し、障害時は兄弟の取り消しを要求し、正常・異常のスコープ終了前に直接の子を合流します。従来のspawn、元の本体・従来エラー、同期的Dropの限界を維持します。HTTPの失敗伝播や障害エスカレーションAPIを変えず、親の`try`を使うSupervisor監視への移行、実行可能なタスク例、分離配布物のタスク検証を提供します。

{/* canonical-item: item-002 */}
- 入力を1つ推論する正規の`std.ownership.move`を追加し、入れ子viewの起点、非同期関数の別名の由来、定数検証、後始末責務を維持します。新しいランタイムヘルパー、clone、割り当てを追加せず、Rustの値渡し`std::convert::identity`を生成します。所有されたコピー不能ローカル値の裸代入を拒否し、新しい値と既存の引数・戻り・フィールド/索引・try・matchによる消費は維持します。現行のコピー規則とFuture制限も維持します。

{/* canonical-item: item-003 */}
- 安定したアプリケーションの同一性、共有依存関係キャッシュ、成功したネイティブビルド世代を分離。同じ生成ディレクトリへの書き込み処理をOSロックで直列化し、以前の成功実行ファイルを保護し、成功後だけlatestを更新する。出力された`native:` パスを使い、`NAGI_NATIVE_TARGET_DIR`は実行ファイル位置ではなく依存関係キャッシュを選ぶ。

{/* canonical-item: item-004 */}
- Rust生成を`check::finalize`と不変な`check::checked::CheckedProgram`の背後に封印します。Rust埋込側はfinalize済みの値を`emit::rust`/`emit::rust_with_lines`へ渡し、可変なプログラム入力は廃止します。パーサー構築で外部`ast::Stmt`構造体リテラルを置換し、公開AST/標準メタデータenumへ所有権、タスク、認証variantを追加します。日英の0.1.11移行ガイドを参照してください。

{/* canonical-item: item-005 */}
- 8つの整数幅に対し、複合式/別名のゼロ除算と符号付きMINの除算・剰余を扱う共通の型付き定数検証器を追加します。デバッグ/リリースのオーバーフロー挙動を維持し、到達不能な定数失敗も文書どおり拒否します。範囲外のRustリテラルを生成せず、符号付きMINの末端値を出力します。

{/* canonical-item: item-006 */}
- 実験的な`std.auth.Principal`と名目的な`Grant[P]`の証明境界を追加し、Nagiからの構築、JSONデコード、コピー、共有を禁止。信頼済みRust/Axumアダプターによる独自認可を例示しますが、固定資格情報を使い、JWS検証や一般的な認可解析は実装しません。

{/* canonical-item: item-007 */}
- マップ済みRustエラーは既定で簡潔にし、`build/run --rust-diagnostics`で生成Rust詳細を保持。ネイティブ、依存関係、マップ不能エラーは表示を維持。明示move、関数値、複数の借用元、純粋な非同期Result/Optionを含め、適合性コーパスを42ソース、有限の生成を18文法へ拡張。

{/* canonical-item: item-008 */}
- viewを含むList、Result、Optionの復元を、別名、入れ子の値、分岐、ループ、asyncを含む単一の非公開検査済みフロープランで低水準化します。ペイロードをcloneせず、ソース上の後始末位置、置換前のRHS評価、キャンセルを維持します。組み込み名から再構築せず、checkerが記録したmove/借用と最終ループの事実を使います。

{/* canonical-item: item-009 */}
- 本文がviewを使うが返さない関数を含め、scope本体を同じコルーチンに保ち、ローカルviewが追加の非同期境界を越えないようにする。High、保存済みLow、手書きLowを通じ、入れ子の本体/合流エラー、通常エラー時の完了済み兄弟取消、親Future破棄、本体のパニックを実ランタイムで検証。

{/* canonical-item: item-010 */}
- クロージャを使わず遅延評価する`env`フォールバックを生成し、ソースレベルの`try`/`await`のエラー・非同期コンテキストを維持します。省略された短絡評価のオペランドとenvフォールバックのタスク受領記録の責務を維持し、常に評価される左辺/キーの受領記録を強制評価せず保持します。3形式で値の存在/欠如、フォールバック失敗、条件付き消費を検証します。

{/* canonical-item: item-011 */}
- リポジトリ開発用AGENTS.md、モデル別の専用エージェント、明示的な言語契約、コンパイラのパイプライン/調査メモ、失敗成果物と縮小処理を伴う有限のプログラム生成、段階的なfuzzスモークテストを追加します。PRのCIでは有限コーパスを、週次CIではより大きな固定seed探索を実行します。

{/* canonical-item: item-012 */}
- 戻りで終了するブロック内の連続直接view代入へ別々の推論生存期間を付与。High、保存済みLow、手書きLowで復元された入力viewと以前の入れ子の戻りをコンパイル・実行し、継続分岐とループ更新を維持。

{/* canonical-item: item-013 */}
- Rust externの引数不一致と同期/非同期の不一致を、High、保存済みLow、手書きLowでソースマップ付きビルド診断として検証します。

{/* canonical-item: item-014 */}
- 生成されたscopeコードを実ランタイムで動かし、子タスクのエラー、子タスクのパニック、本体のエラー伝播、完了済み兄弟取消を3つのソース形式すべてで検証。
