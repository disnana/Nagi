HTTP・認証・Session/CSRF・HTTPS・SQLiteの安全な標準境界を広げた版です。

- 正本ID：`nagi-0-2-0`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- 明示HTTP authentication 方針、有限Host/authority、有限応答/流量 予算、経路 流量 ruleを要求します。応答 生成関数は実リクエストのResponseContextを借用して結果を返し、エラー マッパーもcontextを明示受領します。予算不足はlisten前に拒否します。

{/* canonical-item: item-002 */}
- durable Session発行・rotation・revocation、有限で再利用可能なauthenticated CSRF トークン、別枠の有限one-use pre-login 状態、CORS finalization、固定Ed25519 verification-only プロファイルを接続します。業務 エラーとauth/ランタイム 失敗を分け、元期限、revocation gate、実取り消し 合流を維持します。

{/* canonical-item: item-003 */}
- 型付き HTML/SQLと登録HTTPS操作を接続します。outbound リクエストは検査済み DNS candidate、TCPだけの有限failover、1操作TTL=0、通常TLS検証、有限本文を使い、送信開始後の自動再送や暗黙decompressionをしません。compressionは0.2.1以降の別タスクです。

{/* canonical-item: item-004 */}
- HTTP 方針・Host・応答/流量 予算を明示する安全基盤を候補実装へ接続します。ResponseContextは実リクエストから借用し、生成関数/マッパーは結果で失敗を返します。Session/CSRF/CORS・Ed25519・型付き HTML/SQL・用途別HTTPSの保証と移行は日本語ガイドを参照してください。process-ローカル制限は複数台全体制限ではなく、OOMからの普遍的回復も保証しません。

{/* canonical-item: item-005 */}
- canonical `std.db.sqlite` Poolとaffine Tx APIを、所有 Parameters、非公開 direct-リテラル Query、構造化失敗/Outcome、観測可能終了付きで公開します。acquisition 予算はSQL実行・busy handlingと別で、取り消しはコミット済みworkを元に戻しません。

{/* canonical-item: item-006 */}
- legacy Db/db_*実行をdowngrade経路なしで削除します。元ソース 移行診断、引数 束縛、トランザクション 後始末、実ネイティブ 合流を維持し、日英移行 ガイドに置換codeと保証を示します。

{/* canonical-item: item-007 */}
- deadpoolではなく既存Tokio semaphoreとlazy SQLite アダプターを使います。検査済み 容量と回復可能reservation refusalはOOMからの普遍的回復を保証しません。
