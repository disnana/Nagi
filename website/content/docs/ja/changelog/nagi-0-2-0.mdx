HTTP・認証・Session/CSRF・HTTPS・SQLiteの安全な標準境界を広げた版です。

- 正本ID：`nagi-0-2-0`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- 明示的なHTTP認証方針、有限のHost/authority、有限の応答/流量予算、経路の流量規則を要求します。応答生成関数は実リクエストのResponseContextを借用して結果を返し、エラーマッパーもコンテキストを明示的に受け取ります。予算不足はlisten前に拒否します。

{/* canonical-item: item-002 */}
- 永続Session発行・ローテーション・失効、有限で再利用可能な認証済みCSRFトークン、別枠の有限一回限りのログイン前の状態、CORSの確定処理、固定Ed25519検証専用プロファイルを接続します。業務エラーと認証/ランタイム失敗を分け、元期限、失効ゲート、実際の取り消し処理への合流を維持します。

{/* canonical-item: item-003 */}
- 型付きHTML/SQLと登録HTTPS操作を接続します。外向きリクエストは検査済みDNS候補、TCPだけの有限回のフェイルオーバー、1操作TTL=0、通常のTLS検証、有限の本文を使い、送信開始後の自動再送や暗黙の展開をしません。圧縮は0.2.1以降の別タスクです。

{/* canonical-item: item-004 */}
- HTTP方針・Host・応答/流量予算を明示する安全基盤を候補実装へ接続します。ResponseContextは実リクエストから借用し、生成関数/マッパーは結果で失敗を返します。Session/CSRF/CORS・Ed25519・型付きHTML/SQL・用途別HTTPSの保証と移行は日本語ガイドを参照してください。プロセスローカル制限は複数台全体制限ではなく、OOMからの普遍的回復も保証しません。

{/* canonical-item: item-005 */}
- 正規の`std.db.sqlite` PoolとアフィンなTx APIを、所有権を持つParameters、非公開の直接リテラルQuery、構造化された失敗/Outcome、観測可能な終了処理とともに公開します。取得予算はSQL実行・busy処理と別で、取り消しはコミット済み処理を元に戻しません。

{/* canonical-item: item-006 */}
- 旧Db/db_*実行をダウングレード経路なしで削除します。元ソース上の移行診断、引数の束縛、トランザクションの後始末、実ネイティブ処理への合流を維持し、日英移行ガイドに置換コードと保証を示します。

{/* canonical-item: item-007 */}
- deadpoolではなく既存Tokioセマフォと遅延初期化するSQLiteアダプターを使います。検査済み容量と回復可能予約拒否はOOMからの普遍的回復を保証しません。
