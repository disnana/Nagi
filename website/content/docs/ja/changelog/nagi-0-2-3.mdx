Windows GNU Rust toolchainのproject modeで発生するlink失敗を修正した版です。

- 公開日：`2026-10-30`
- 正規ID：`nagi-0-2-3`
- 状態：`公開済み`

## 変更内容

{/* canonical-item: item-001 */}
- WindowsのGNU Rust toolchainでproject modeを使うと、正規化済みの`\\?\`形式のCargo target pathがGNU linkerへ渡り、明示的なsource file指定では成功する同じprojectがlinkに失敗する場合がある問題を修正します。既定project targetだけを、意味が変わらない短いdrive/UNC pathの場合に限って外部tool向け表記へ変換します。明示`NAGI_NATIVE_TARGET_DIR`、長いpath、末尾のdot/space、予約device名は変更しません。

## 正本との対応

版、日付、順序、項目の正本はリポジトリ直下の[変更履歴](https://github.com/disnana/Nagi/blob/main/CHANGELOG.md)です。このページは正本の`2`個の箇条書きを、日本語と英語の重複をまとめた`1`個の項目として表示します。正本が変わった場合、検証は両言語ページの更新が終わるまで失敗します。
