コピー不能なListの反復、Resultのエラー変換、Supervisorの準備完了、null許容SQLite、実行例を追加した版です。

- 正本ID：`nagi-0-1-9`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- コピー不能なList要素を読み取り専用の`for`で反復できるようにし、所有権・生存期間検査を行います。コピーによる反復は維持します。

{/* canonical-item: item-002 */}
- 同期関数による明示的な型付きエラー変換`std.result.map_error`を追加し、`try`のエラー同一性と借用した成功値を維持します。

{/* canonical-item: item-003 */}
- 明示的なタスク準備完了と型付き有限Supervisorイベントの待機を追加し、重複・古い・非アクティブな準備完了通知を拒否します。

{/* canonical-item: item-004 */}
- 借用したJSONの`Content-Type`検証を追加し、見積もりAPIのサンプルは中間コピーなしでハンドラーラッパーのリクエストIDを保持します。

{/* canonical-item: item-005 */}
- 手書きLowで複数行呼び出し、コンストラクター、List、索引、関数型を受理し、文の境界とソース診断を維持します。

{/* canonical-item: item-006 */}
- ソースファイルの別名、埋め込み成果物、Rustアダプター、マニフェストを含む生成出力の重複を書き込み前に拒否します。

{/* canonical-item: item-007 */}
- 索引、比較、保存したviewで借用と衝突する追加moveを検出し、対応済み即時読み取り、独立フィールド、コピー、ループでの再代入を維持します。

{/* canonical-item: item-008 */}
- bool、float、バイトを含む対応するスカラー行型のnull許容SQLiteカラムをデコードし、保存済みLowで入れ子のOptionを維持します。

{/* canonical-item: item-009 */}
- 正常停止中も、正常な処理中のリクエストが完了するまでHTTP応答の送信期限を有効に保ちます。

{/* canonical-item: item-010 */}
- Rustバックエンドの原因注記をNagiソース位置へ対応付け、読みやすいインポート名を表示し、ネイティブRust診断と修正候補を維持します。

{/* canonical-item: item-011 */}
- 定数整数演算のリリース時のラップとデバッグ時のオーバーフロー検査を維持します。`include_text`というローカルコールバックを通常呼び出しとして扱い、コピー済みListのviewに必要な実際のClone要件を報告します。

{/* canonical-item: item-012 */}
- モジュール間のedgeをHTMLマップの表示領域内に保ち、グループ件数を正確に表示します。

{/* canonical-item: item-013 */}
- stock-report、device-settings、seat-reservations、file-json、quote-api、supervised-worker、手書きLowのorder-quote実行プロジェクトを追加し、High・保存済みLow・直接記述したLowでネイティブ動作を検証します。

{/* canonical-item: item-014 */}
- コンパイラ進捗を標準エラー出力へ送り、コストレポート有効時も`nagic run`の標準出力をアプリケーション出力専用に保ちます。

{/* canonical-item: item-015 */}
- 同一入力の配布アーカイブを再現可能にし、再開したドラフトリリースが検証済み成果物を再利用できるようにします。
