non-コピー List 反復、結果 エラー変換、Supervisor 準備完了、null許容 SQLite、実行例を追加した版です。

- 正本ID：`nagi-0-1-9`
- 状態：`公開済み`

## 変更項目

{/* canonical-item: item-001 */}
- non-コピー List要素を読み取り専用 `for`で反復できるようにし、所有権・生存期間検査を行います。コピー反復は維持します。

{/* canonical-item: item-002 */}
- 同期関数による明示的な型付きエラー変換`std.result.map_error`を追加し、`try`のエラー 同一性と借用した success値を維持します。

{/* canonical-item: item-003 */}
- 明示タスク 準備完了と型付き有限Supervisor イベント waitを追加し、重複・stale・inactive 準備完了 signalを拒否します。

{/* canonical-item: item-004 */}
- 借用した JSON Content-型 検証を追加し、quote API sampleは中間コピーなしでハンドラー ラッパーのリクエスト IDを保持します。

{/* canonical-item: item-005 */}
- handwritten Lowでmultiline 呼び出し、コンストラクター、List、索引、関数 型を受理し、statement境界とソース診断を維持します。

{/* canonical-item: item-006 */}
- ソース ファイル 別名、embedded 成果物、Rust アダプター、manifestを含む生成出力の重複を書き込み前に拒否します。

{/* canonical-item: item-007 */}
- 索引、comparison、保存した viewで借用と衝突する追加moveを検出し、対応済みimmediate 読み取り、独立フィールド、コピー、ループ reassignmentを維持します。

{/* canonical-item: item-008 */}
- bool、float、バイトを含む対応scalar 行 型のnull許容 SQLite columnをデコードし、保存済み Lowで入れ子 Optionを維持します。

{/* canonical-item: item-009 */}
- graceful 停止中もhealthy in-flight リクエスト完了までHTTP 応答 send 期限を有効に保ちます。

{/* canonical-item: item-010 */}
- Rust バックエンド cause 注記をNagi ソース位置へ対応付け、読みやすいインポート名を表示し、ネイティブ Rust診断とsuggestionを維持します。

{/* canonical-item: item-011 */}
- 定数 integer arithmeticのリリース wrappingとデバッグ overflow checkを維持します。`include_text`というローカル callbackを通常呼び出しとして扱い、copied List viewに必要な実際のClone要件を報告します。

{/* canonical-item: item-012 */}
- cross-モジュール edgeをHTML マップ viewport内に保ち、group 件数を正確にlabelします。

{/* canonical-item: item-013 */}
- stock-report、device-settings、seat-reservations、ファイル-json、quote-api、supervised-ワーカー、handwritten Low order-quoteの実行プロジェクトを追加し、High・保存済み Low・direct Lowでネイティブ動作を検証します。

{/* canonical-item: item-014 */}
- コンパイラ進捗をstderrへ送り、cost report有効時も`nagic run` stdoutをアプリケーション出力専用に保ちます。

{/* canonical-item: item-015 */}
- 同一入力の配布archiveを再現可能にし、再開したdraft リリースが検証済み成果物を再利用できるようにします。
