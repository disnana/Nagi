```nagi title="functions.nagi"
def double(value: i64) -> i64:
    return value * 2

def main():
    answer = double(21)
    print(answer)
```

`value: i64` declares the parameter type, and `-> i64` declares the result type. The compiler checks that the value after `return` agrees with the declaration. The caller also infers `answer` as `i64`.

```sh
nagic check functions.nagi --no-project
nagic run functions.nagi --no-project --profile dev
```

```text
42
```
