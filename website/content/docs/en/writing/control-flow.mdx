```nagi title="control_flow.nagi"
def main():
    total = 10
    if total >= 10:
        print("enough")
    else:
        print("short")

    for index in range(3):
        print(index)

    remaining = 2
    while remaining > 0:
        remaining -= 1
    print(remaining)
```

`if` runs only the branch whose condition is `True`. The `for` loop receives values `0` through `2` from `range(3)`, and `while` repeats while its condition remains `True`. Indentation defines each block.

## Support

Nagi 0.2.2 High syntax uses `if` and `else`. `elif` is an Unreleased feature under development, so it does not appear in published-version code.
