```nagi title="variables.nagi"
def main():
    count: i64 = 3
    label = "tasks"
    ready = True
    print(count)
    print(label)
    print(ready)
```

`count: i64` has an explicit type. Nagi infers `str` and `bool` for `label` and `ready` from their values. Type checking happens before Rust generation, so an incompatible assignment is rejected before native compilation.

```sh
nagic check variables.nagi --no-project
nagic run variables.nagi --no-project --profile dev
```

```text
3
tasks
true
```
