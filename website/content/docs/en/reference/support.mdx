| Capability | Rust target 0.2.3 | Continue with |
|---|---|---|

### Main current limits

- The standard HTTP API does not provide PostgreSQL, WebSocket, HTTP/2, streaming, or server-side TLS.
- Actors are Tokio tasks in one process. They do not promise the same isolation as BEAM processes.
- `elif` and named function arguments are Unreleased. Do not use them in source for published 0.2.3.

## Go target under development

This section describes unreleased work toward 0.3.0. Published Nagi 0.2.3 does not include the Go target.

| Capability | Development status |
|---|---|
| Native builds and basic features | Select explicitly with `--backend go`. Supports a subset of basic types, functions, classes, `Option`, `Result`, `try`, and ownership. |
| Async | Supports a limited subset including direct `await` of user-defined async functions and `sleep`. Public `Task`, `scope`, and `spawn` are unsupported. |
| HTTP (M21) | Verified direct `serve` on IPv4 loopback with exact-match public `GET` and `POST` routes, bodyless GET, and fixed-length binary POST echo and body limits. |
| HTTP state (M39) | Verified shared read-only State made of scalars and strings in named handlers with no `await`. Shared mutable State and handlers that suspend and resume are outside this scope. |
| CORS | Verified allowed origins and `OPTIONS` preflight on routes that opt in with `cors_policy` and `cors_route`. Routes without CORS configuration add no CORS headers. |
| Integer conversion | `i32(i64)` checks the range and returns an `Error` for out-of-range inputs. Existing lossless widening to `i64` is also supported. |
| Error inspection | `error_kind` reads the kind of supported Go errors without consuming them. `error_message` reads the message. |
| Integer parsing | `parse_i64` accepts strings and read-only string views. Its decimal range, failure kinds, and error messages match the Rust backend. |
| JSON | Standalone `json_encode` supports `str`, `bool`, and integers. Float and aggregate encoding, `json_decode`, and HTTP JSON responses are unsupported. |
| Unsupported standard features | Public Actor and Supervisor APIs, SQLite Pool/Tx, authentication, sessions, and CSRF are unsupported. |
| Native adapters | Go native adapters are unsupported. The Go target rejects Rust assets. |

The HTTP tests used the standard CLI on Linux with High, generated and saved Low, and handwritten Low. The distribution smoke check uses the explicit `--go-smoke` option and an external Go toolchain. These are Linux development checks. Other operating systems and formal distribution require separate verification.
