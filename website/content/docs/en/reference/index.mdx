- [`std.http.server` response limits](./http-response-limits): names all twelve values and explains their units and failure conditions.
- [Changelog](../changelog): separates published releases from Unreleased work.
- [Complete source projects](https://github.com/disnana/Nagi/tree/main/test-nagi-code): HTTP, SQLite, Actor, and Rust adapter projects.
- [Published release](https://github.com/disnana/Nagi/releases/tag/nagi-v0.2.3): compiler and distributions for Nagi 0.2.3.

Even when looking for one API name, check the target and version first. Unreleased syntax and the Go implementation planned for 0.3.0 are not part of published Nagi 0.2.3.
