Language basics

Check before running.

Nagi checks types and how you use data after passing it to another function. Operations that can fail return a result you can handle as success or failure.

Where the name comes from

Nagi is Japanese for a calm sea.

Even when the inside is working intensely,
the surface stays as calm as a quiet sea.

The name comes from the Japanese word 凪 (nagi): a lull in the wind and a calm sea. It expresses an idea behind the language: even when much is happening underneath, the code you work with should feel calm and clear.

Development status

Taking shape, step by step.

Nagi is a 0.1 prototype. Its syntax and features are still being developed and may change. The Docs distinguish working features from those that have yet to be implemented.

Builds and execution have been verified on Linux x86_64 and Windows. macOS has not been verified. You need Rust/Cargo and a C build environment to try Nagi.
