Reasoning: TaskScope is the only JoinSet consumer. record publishes every native join into ticket accounting synchronously, so an empty JoinSet is sufficient to skip a redundant drain for the sticky primary branch. When joins remain, receive still awaits their actual drain before returning a fault. Once drained, the branch clones the same primary cause, drops its Task (publishing ABANDONED before dropping buffered T), and retires that one joined ticket. Primary/related cause retention, requested cancellation, and actual-join responsibility remain unchanged. Arbitrary buffered-T Drop panic remains within the existing explicitly excluded recovery boundary; published abandonment permits a later explicit drain sweep if normal execution resumes. External Task Drops continue to be swept by explicit join/drain as before.
